# Тетрадь фокуса

Личный трекер дня для одного человека: жёсткий распорядок с протоколами внутри блоков, помодоро с фиксацией срывов, тренировки с прогрессией, тренажёр чисел, ораторство, режим сна, разряды-печати и AI-ассистент, который перестраивает расписание через дифф с подтверждением.

PWA: ставится иконкой на iOS, Android и десктоп, работает офлайн, синхронизируется через Supabase.

## Стек

Vite · React 19 · TypeScript (strict) · Tailwind 4 · Dexie (IndexedDB) · Supabase (Auth, Postgres, RLS, Edge Functions) · DeepSeek через серверный прокси · Vitest.

## Команды

```bash
npm install
npm run dev        # локальный запуск
npm test           # тесты чистой логики
npm run lint       # oxlint
npm run format     # prettier
npm run build      # production-сборка в dist/
```

Установка, деплой и настройка аккаунтов — в [SETUP.md](./SETUP.md).

## AI-ассистент: выключен по умолчанию

Код ассистента в проекте есть (`src/ai`, `src/features/assistant`, `supabase/functions/ai`), но спрятан за флагом. Пока флаг выключен, в приложении нет кнопки ассистента и экрана чата, и оно ни разу не обращается к прокси. Офлайновые подсказки — к шагам протоколов, по итогам тренировки, по чистоте фокуса и по дню — работают всегда: они считаются на устройстве и от API не зависят.

Чтобы включить ассистента позже:

1. **Секрет на сервере.** Задеплоить функцию `ai` и положить ключ в секреты Supabase (SETUP.md, раздел 4):
   ```bash
   supabase secrets set DEEPSEEK_API_KEY=sk-… DEEPSEEK_BASE_URL=https://api.deepseek.com DEEPSEEK_MODEL=deepseek-chat
   supabase functions deploy ai
   ```
2. **Флаг в сборке.** В `.env` (локально) и в Environment Variables на Vercel добавить
   ```
   VITE_ASSISTANT_ENABLED=true
   ```
   и пересобрать (на Vercel — Redeploy). Флаг читается на этапе сборки: менять его в работающем приложении нельзя, только пересборкой.
3. **Проверка.** `npm run test:live` гоняет ассистента против настоящего DeepSeek, ключ берётся из `~/.config/focus-notebook/deepseek.env` (файл вида `DEEPSEEK_API_KEY=sk-…`, права 600). Без файла тест пропускается.

Выключить обратно — убрать флаг (или поставить `false`) и пересобрать; секрет на сервере можно оставить.

## Как устроено

- **Источник правды — локальная база** (IndexedDB). Всё пишется сначала туда, синхронизация догоняет сервер, конфликты решаются по `updated_at` (побеждает более поздняя запись, на сервере это закреплено триггером).
- **Расписание — данные, не код.** Стартовый шаблон один раз попадает в базу и дальше правится в интерфейсе или ассистентом.
- **Подсказки к шагам протоколов лежат в словарях** и работают без сети. DeepSeek нужен только ассистенту.
- **Ключ DeepSeek не покидает сервер:** приложение ходит в Supabase Edge Function, которая проверяет сессию, считает лимиты и стримит ответ.
- **Три языка** — `src/i18n`. Тип ключей выводится из русского словаря: непереведённая строка не даст собрать проект, тест дополнительно проверяет, что кириллица не протекла в другие языки.
